# Module 1: Telco Customer Churn Prediction & Decision Modeling

## 📌 Project Overview
This project analyzes customer churn in the telecommunications industry using Python and machine learning. It explores customer behavior, identifies churn patterns, builds predictive models, and evaluates decision thresholds to support cost-effective customer retention strategies.

## 🎯 Objectives
- Clean and preprocess the customer dataset.
- Perform Exploratory Data Analysis (EDA) to identify churn patterns.
- Train and compare Logistic Regression and Random Forest models.
- Evaluate model performance using Accuracy, Precision, Recall, F1-Score, and ROC-AUC.
- Analyze decision thresholds to balance Precision and Recall.
- Estimate potential retention campaign costs, benefits, and ROI using business assumptions.

## 🛠️ Tools & Technologies
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Jupyter Notebook
- Git and GitHub

## 📂 Project Tasks
1. **Data Cleaning & Preprocessing** — Handle missing values and prepare data for analysis.
2. **Exploratory Data Analysis** — Analyze churn patterns based on customer tenure, contract type, and other features.
3. **Machine Learning Model Training** — Train classification models to predict customer churn.
4. **Model Evaluation** — Compare model performance using classification metrics.
5. **Business Decision Threshold Modeling** — Evaluate Precision–Recall trade-offs and estimate retention campaign ROI.

## 📊 Expected Outcomes
- Identify customer groups with a higher likelihood of churn.
- Compare the performance of different machine learning models.
- Select a potential decision threshold based on business objectives.
- Support data-driven customer retention planning.

## 💼 Business Impact
The project demonstrates how data analytics and machine learning can help businesses identify at-risk customers, prioritize retention campaigns, and evaluate potential campaign profitability.

**Note:** Retention benefits and ROI are estimates based on stated assumptions, not actual campaign results.
